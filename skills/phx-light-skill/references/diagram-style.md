# 极简光位图设计规范(按需输出)

用户要求"光位图/光位参考图"时才生成。风格:极简、克制、信息明确。

## 视觉规则

- 底色:纯白/浅灰,无渐变、无纹理、无厚重阴影。
- 线条:细线为主(视觉宽度 1–2px),不用粗描边。
- 用色:每盏灯一个颜色(如主光暖橙、轮廓冷蓝、补光灰),最多 3 色加灰;不使用大面积色块。
- 符号约定:圆点=灯位;细箭头=光向;虚线=弱光/补光;简洁几何人形表示人物姿态(含动作朝向与高低)。
- 文字:只保留灯名与关键参数(方位、光比),标签尽量少;方位用"相对人物/机位"描述,不用钟点位。
- 图式:优先单一俯视空间图(标人物姿态、空间参照物、相机);需要高度信息时补一张同风格立面图。
- 禁止:3D 渲染、渐变光晕、厚重阴影、装饰图标、花哨字体、钟点位标注。

## 实现

- 优先内联 SVG(可缩放、无字体依赖);确需位图时用环境可用的绘图工具,不硬依赖固定脚本。
- 每张图配一行简短说明:光比、复刻顺序,与文字分析的结论保持一致。
