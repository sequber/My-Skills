# 判光线索库(证据 → 推断)

判据都放在"动作-机位"语境里读;一个线索给出倾向,多个线索互证才落结论。拿不准就降置信度或标注"仅见于该张"。

## 塑形光 vs 填充光

- 主光是离轴方向光(侧/四分之三/背/顶/高位斜射),不是面光;面光=平板、丑,只作填充。凡推成"正面均匀主光"先判错。
- 画面有从亮到暗的明暗梯度、体积转折、可辨认阴影方向 → 塑形光(主光)所在。
- 受光面均匀、阴影软、几乎无方向感 → 弱而大的填充光,不是主光。
- 画面整体均匀、平,看不出主光 → 填充光主导;此时从"最亮集中的高光"和"明暗转折"反向找主光。
- 画面可见的发光道具(灯/烛台/灯罩)不一定是主光,常只是道具/氛围/勾边;定主光看人物自身受光梯度与高光方位,别按"哪盏在发亮"判。

## 光向与高度

- 最强最集中的高光位置 → 光源朝向(高光在发顶 → 光在上方;在脸侧 → 光在侧面)。
- 明暗转折方向 → 光压下来的方向。
- 采样别落在光源/道具自身(灯珠、灯罩常过曝或与背景串色,读数不稳);量它**照亮的那块受光面**才可信。
- 轮廓/背光可落在背对主光的那条边缘,且常与背景同色——别把该侧当纯阴影,先扫边缘再定。
- 阴影落点与边缘:阴影在与光源相反的一侧;软边=扩散;硬边=收窄/硬光。
- 双影 → 多灯或环境光参与。

## 光色

- 高光偏暖橙 → 低色温灯/CTO;偏冷蓝 → 高色温灯/CTB/环境蓝。
- 判主光色温别采银发/金属等强反光面(暖光下易泛冷 sheen);采皮肤等漫反射面才准。
- 人物与背景的色温差 → 冷暖分离布光;先问是现场滤片还是后期统一调色。

## 光质与附件

- 眼神光形状:细圆点 → 伞/八角箱/小柔箱或远距光源;宽矩形 → 方形柔箱;竖长条 → 条形箱/条灯;空心圆环 → 环形灯;点在瞳孔偏上 → 光源偏高。
- 阴影边缘:渐变宽 → 柔;锐利 → 硬。
- 高光形态:面积大而光滑 → 扩散附件;小而刺眼 → 小光源/裸灯。
- 背景/地面溢出成界限块 → 有遮光板/蜂巢/束光筒;均匀洒开 → 大柔光源或环境光。

## 特殊光位

- 顶光:发顶高光集中、光自上往下压、下巴/眼眶/身体下方渐暗 → 高位偏硬小范围束光。
- 高位可能有两盏(别按亮度合并):发冠集中爆白 + 正下方枕头/邻面直接发光、往下几厘米内锐衰减 → 正上方独立硬顶光;脸/胸左右明暗梯度、光沿面走 → 前方偏侧暖主光。朝向面不同就分灯。
- 地面/低位背景灯:地面或低处有明确受光面、光从低处贴地斜上打 → 独立地面灯,别误判成溢光或后期。
- 无独立受光面的背景色偏 → 溢光/环境反光/后期,不拆独立灯。

## 高反光材质

- 银白/白假发、绸缎、金属在硬顶光下烧成爆白、并让紧邻枕头/邻面发光 → 窄硬光源(独立顶光)的信号,不是大柔箱的柔和过渡。

## 聚焦点与黑白灰

- 最亮最拉视线的点(眼神光、发丝亮边、皮肤高光、道具反光)→ 该盏灯与材质共同造成。
- 每盏灯都要能说清:它把画面哪些区域提亮、哪些压暗,如何参与整体黑白灰分布。
- 暗部死黑 → 无补光或刻意压黑;暗部有冷灰层次 → 有低功率补光/环境反弹。

## 主次判别参考

常见组合与主次:

- 暖主光 + 冷轮廓/背景 → 暖灯塑形,冷灯分离,冷暖对比拉开层次。
- 头顶硬束光 + 正面弱填充 → 顶光塑形,填充只抬暗部。
- 冷主光 + 暖地面/背景 → 冷灯塑形,低处暖灯铺氛围。

判断时永远先问:哪盏有方向感和明暗转折(塑形),哪盏只是把光填平(填充)。
